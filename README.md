# Educational Platform
Современная образовательная онлайн-платформа для создания курсов, управления контентом и монетизации знаний.

## Описание
Проект представляет собой бэкенд-ядро образовательной платформы. Сервис позволяет авторам создавать учебные 
материалы, студентам — записываться на курсы и оплачивать подписки, а администраторам — управлять пользователями. 
Архитектура построена с использованием `Django REST Framework`, асинхронных задач через `Celery` и контейнеризации `Docker`.

## Функционал
* Управление курсами: создание категорий, курсов и уроков (приложение `materials`).
* Пользователи и роли: регистрация студентов, профили авторов, разграничение прав доступа (приложение `users`).
* Подписки и оплата: интеграция со `Stripe` для обработки регулярных платежей за доступ к контенту (приложение `subscriptions`).
* Асинхронные задачи:
Рассылка `email`-уведомлений о новых уроках или платежах.
Генерация чеков после оплаты.
Периодические отчеты (через сервис `celery-beat`).
* Администрирование: расширенная панель администратора `Django` для ручного контроля данных.

## Зависимости 
* Язык: `Python 3.14`
* Фреймворк: `Django 6.0.7`, `Django REST Framework`
* База данных: `PostgreSQL 16.14`
* Кэш/Очередь: `Redis 8.x` (с модулями `Search`, `JSON`, `Bloom`)
* Задачи: `Celery 5.6.3` + `django-celery-beat`
* Инфраструктура: `Docker`, `Docker Compose v3.9`
* Оплата: `Stripe` `SDK` версии `15.3.1`

(Полный список пакетов находится в вашем файле `requirements.txt`)

## Тестирование
Для обеспечения качества кода используются:

* `Unit`-тесты стандартной библиотеки `Django` (`python manage.py test`).
* Статический анализатор `Flake8` (указан в зависимостях).
* Покрытие тестами отслеживается через `Coverage.py`.

```
docker compose exec web python manage.py test
```

## Запуск приложения
В терминале из корня проекта выполните команду сборки и запуска всех сервисов:

```
docker compose up --build
```

Приложение автоматически выполнит миграции базы данных (`python manage.py migrate`), 
создаст необходимые тома для статики и запустит веб-сервер вместе с воркерами `Celery`.

Полезные команды:

* Посмотреть логи конкретного сервиса: `docker compose logs -f web`
* Выполнить команду внутри контейнера: `docker compose exec web python manage.py createsuperuser`
* Полная остановка и удаление томов (очистка БД): `docker compose down -v`
